HTML Helper - Frontend-Only Application

ℹ️ No API Testing Required

HTML Helper is a pure frontend application with no backend API. All functionality runs entirely in the browser.

🛠️ Technology Stack

  • Frontend: Vite + TypeScript + Tailwind CSS
  • Storage: LocalForage (IndexedDB/localStorage)
  • Security: DOMPurify + Sandboxed Iframes
  • Animations: Anime.js
  • Code Editor: CodeMirror 6

✅ Testing the Application

To test HTML Helper locally:

  1. Install dependencies: npm install
  2. Start dev server: npm run dev
  3. Open browser to: http://localhost:3000
  4. Try the interactive demo on the landing page
  5. Click "Start Learning" to begin lessons

🔍 Features to Test

  • Landing Page: Interactive HTML demo with live preview
  • Code Editor: Type HTML and see real-time rendering
  • Validation: Click "Check Answer" to validate your code
  • Animations: Watch for confetti on lesson completion
  • Progress: Your progress saves automatically in browser
  • Achievements: Unlock badges as you complete lessons
  • Lesson Map: Click menu to see all 15 lessons

🔒 Security Features

  • HTML Sanitization: DOMPurify removes malicious code
  • Sandboxed Execution: Code runs in isolated iframe
  • Rate Limiting: Max 50 executions per minute
  • Timeout Protection: 5-second execution limit
  • No Server: All processing happens client-side

📊 Performance

  • Bundle Size: < 150KB gzipped
  • First Contentful Paint: < 1.5s on 3G
  • Animation FPS: 60 FPS target
  • Lighthouse Score: > 95 target

🚀 Deployment

This application can be deployed to any static hosting service:

  • Netlify (recommended)
  • Vercel
  • GitHub Pages
  • Cloudflare Pages

Simply run npm run build and deploy the dist folder.

📝 Note

Since there is no backend API, there are no endpoints to test. All data persistence uses browser localStorage/IndexedDB through LocalForage.
