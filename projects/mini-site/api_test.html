Countdown Timer - Test Cases

Manual test plan for the countdown timer application. No APIs — this is a client-side only app.

1. Initial State

TC-01: Page loads with correct initial state

  1. Open the application in a browser

Expected: Timer shows "01:00", status says "Ready", only "Start" button visible, progress ring is full (no offset).

2. Timer Controls

TC-02: Start countdown

  1. Click the "Start" button

Expected: Timer begins counting down from 01:00. Button label changes to "Pause". "Reset" button appears. Status reads "Counting down". Progress ring begins depleting.

TC-03: Pause countdown

  1. Start the timer
  2. Click "Pause" while timer is running

Expected: Timer stops. Button label changes to "Resume". Status reads "Paused". Progress ring freezes at current position.

TC-04: Resume countdown

  1. Start, then pause the timer
  2. Click "Resume"

Expected: Timer resumes from paused time. Button reverts to "Pause". Status reads "Counting down".

TC-05: Reset countdown

  1. Start the timer, let it run a few seconds
  2. Click "Reset"

Expected: Timer resets to 01:00. Status reads "Ready". Only "Start" button visible. Progress ring returns to full.

TC-06: Timer reaches zero

  1. Start the timer and wait until it reaches 00:00

Expected: Timer shows "00:00". Status reads "Time's up". "Start" button hidden, only "Reset" visible. Timer digits pulse slowly for ~4 seconds.

3. Visual Feedback

TC-07: Danger state under 10 seconds

  1. Start the timer
  2. Observe when timer reaches 00:10

Expected: Timer digits change to red (#E85454). Progress ring turns red. Glow effect shifts to red.

TC-08: Progress ring animation

  1. Start the timer
  2. Observe the SVG progress ring

Expected: Ring smoothly depletes counterclockwise over 60 seconds. Transition is smooth (0.35s ease).

4. Keyboard Shortcuts

TC-09: Space to start/pause

  1. Press Space when idle
  2. Press Space while running
  3. Press Space while paused

Expected: Space toggles between start/pause/resume, same as clicking the primary button.

TC-10: R to reset

  1. Start the timer
  2. Press R

Expected: Timer resets to 01:00, same as clicking Reset.

5. Edge Cases

TC-11: Multiple rapid clicks on Start

  1. Click "Start" rapidly 5 times

Expected: Timer starts once and functions normally. No duplicate intervals or racing conditions.

TC-12: Reset while paused

  1. Start, then pause the timer
  2. Click "Reset"

Expected: Timer resets cleanly to 01:00. No lingering intervals.
