# Template Selection

## Chosen Template: `static-html`

## Task Analysis
The task requires a single-page HTML site with a gradient background and centered "Hello World" text. This is a purely visual, static page with no dynamic content, no backend, no routing, and no build-time processing. It's the simplest category of web project.

## Justification
- **No backend needed** — This is a static display page with zero server-side logic
- **No build tools required** — Pure CSS gradients and flexbox centering need no preprocessors or frameworks
- **Single file deliverable** — One HTML file with inline or embedded CSS achieves the full requirement
- **Zero dependencies** — No npm, no package.json, no node_modules — nothing to install or maintain
- **Fastest path to quality** — Less tooling means fewer moving parts and a cleaner result for this scope

## Customizations Needed
- None — using standard template. A single `index.html` with embedded `<style>` is sufficient.
