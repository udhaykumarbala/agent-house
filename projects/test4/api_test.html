DesignFlow — API Endpoints

Note: DesignFlow Phase 1 is a frontend-only application using localStorage for persistence. Backend API endpoints will be added in a future phase. This page documents the planned API contract.

Tasks

GET /api/tasks

List all tasks. Query params: ?state=backlog&category=design

POST /api/tasks

Create a new task. Body: { title, category, priority, dueDate, timeEstimate, ... }

GET /api/tasks/:id

Get a single task by ID

PUT /api/tasks/:id

Update task fields. Body: Partial<Task>

DELETE /api/tasks/:id

Delete a task

PATCH /api/tasks/:id/move

Move task to a new column. Body: { state: IterationState }

PATCH /api/tasks/:id/complete

Toggle task completion

Subtasks

POST /api/tasks/:id/subtasks

Add a subtask. Body: { title: string }

PATCH /api/tasks/:taskId/subtasks/:subtaskId

Toggle subtask completion

DELETE /api/tasks/:taskId/subtasks/:subtaskId

Delete a subtask

Attachments

POST /api/tasks/:id/attachments

Add URL attachment. Body: { url, label? }

DELETE /api/tasks/:taskId/attachments/:attachmentId

Remove an attachment

Settings

GET /api/settings

Get user settings (theme, columns, categories, tags)

PUT /api/settings

Update settings. Body: Partial<Settings>

Data

GET /api/export

Export all tasks as JSON file

POST /api/import

Import tasks from JSON. Body: { tasks: Task[], merge?: boolean }
