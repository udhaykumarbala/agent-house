Rock Paper Scissors — Test Plan

This is a client-side only game — no API endpoints. Tests cover UI interactions and game logic.

Game Logic Tests

Manual Rock beats Scissors
Click Rock. If CPU plays Scissors, result should show "You win!" with green styling.
Manual Paper beats Rock
Click Paper. If CPU plays Rock, result should show "You win!" with green styling.
Manual Scissors beats Paper
Click Scissors. If CPU plays Paper, result should show "You win!" with green styling.
Manual Draw detection
When both choose the same, result should show "It's a draw!" with purple styling.
Manual Loss detection
When CPU's choice beats yours, result should show "You lose!" with red styling.

Score Tracking

Manual Score increments correctly
Play multiple rounds. Verify player/CPU/draw scores increment only on their respective outcomes.
Manual Score animation
When a score changes, it should briefly "pop" (scale up then back down).

UI Interactions

Manual Button hover states
Hovering a choice button should show golden border and scale the emoji up.
Manual Keyboard shortcuts
Press 1/r = Rock, 2/p = Paper, 3/s = Scissors.
Manual History pips
After first round, "Recent" section appears with colored dots: green=win, red=lose, purple=draw.
Manual Streak badge
Win or lose 3+ times in a row to see the streak badge appear in the top-right corner.
Manual Reset functionality
Click "Reset" to clear all scores, history, and return to initial state.
Manual Suspense animation
After clicking a choice, there should be a brief "Choosing..." shake animation before the result appears.
